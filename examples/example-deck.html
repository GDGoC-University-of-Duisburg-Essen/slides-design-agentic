Why Firebase?

What it is and when it fits your project

Firebase lets you ship a full app without running a server

  • Hosting serves your web app worldwide
  • Firestore stores and syncs data in real time
  • Authentication handles sign-in for you
  • Free tier covers most student projects
Mention that all three services are configured from one console and one CLI.

Today's app needs surprisingly little

3Firebase services: Hosting, Firestore, Authentication
1command to deploy: firebase deploy
0servers you have to run or patch yourself

Firestore fits most new projects better than Realtime Database

Cloud Firestore

  • Documents grouped in collections
  • Rich queries with indexes
  • Scales automatically

Realtime Database

  • One large JSON tree
  • Very low-latency sync
  • Simple queries only

Hands-on: your first app

Set up, store data, deploy

Saving an event to Firestore takes a few lines

import { initializeApp } from "firebase/app";
import { getFirestore, collection, addDoc }
  from "firebase/firestore";

const app = initializeApp(firebaseConfig);
const db = getFirestore(app);

await addDoc(collection(db, "events"), {
  title: "DU + TECH = ?",
  date: new Date("2026-12-03"),
});
  • firebaseConfig comes from the console
  • addDoc creates an ID for you

Pick the service that matches what your app needs

Your app needs to …Firebase serviceTypical use
serve the websiteHostingstatic sites, single-page apps
store and sync dataCloud Firestoreevents, chats, to-do lists
let users sign inAuthenticationGoogle, GitHub, e-mail login
store user uploadsCloud Storageprofile pictures, PDFs
run code on a serverCloud Functionse-mails, payments, webhooks

Going further

Pitfalls, takeaways and resources

Three pitfalls we see in almost every first project

Security rulesNever ship the default "allow read, write: if true" rules.
API keysThe web config is public by design - protect data with rules, not secrecy.
EmulatorUse the Local Emulator Suite to test without touching production data.

Ship a small thing early - then iterate.

Our rule of thumb for hackathon projects

Key takeaways

  • Firebase removes server work so you can focus on your idea
  • Start with Hosting, Firestore and Authentication
  • Write security rules before you share the link
  • Test locally with the Emulator Suite
